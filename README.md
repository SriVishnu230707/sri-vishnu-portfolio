# Sri Vishnu portfolio

A responsive project portfolio for Sri Vishnu. The featured build is [MPLADS Sentinel AI](https://github.com/SriVishnu230707/mplads-sentinel-ai); the project gallery can be searched and filtered.

The page fetches public GitHub repository data in the visitor's browser to refresh the original-repository and star counts. It keeps static fallback counts if GitHub is unavailable or rate-limited.

## Local preview

Run `npm run dev` and open http://127.0.0.1:4173.

The site is plain HTML, CSS, and JavaScript with no build step.
